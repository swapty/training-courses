# Контентная рекомендательная система на базе датасета MovieLens

Учебный проект (курсовая работа), посвященный разработке алгоритма персональных рекомендаций фильмов на основе пользовательских предпочтений и жанрового анализа.

## 🛠 Технологический стек
* **Язык программирования:** Python
* **Библиотеки:** Pandas, Matplotlib, Seaborn

## 📈 Какую задачу решает проект?
Проект реализует полноценный конвейер (pipeline) обработки данных и генерации рекомендаций:
1. **Разведочный анализ данных (EDA):** Визуализация распределения пользовательских оценок и выявление топ-10 самых популярных фильмов датасета с помощью `Matplotlib` и `Seaborn`.
2. **Предобработка и фильтрация аномалий:** Реализована защита от статистического шума (ситуаций, когда малоизвестный фильм с 1-2 оценками "5.0" попадает на первые места). Через `Pandas` установлен жесткий порог — в системе учитываются только фильмы, набравшие более 50 оценок.
3. **Генерация рекомендаций (Content-Based Filtering):** Написана функция, которая агрегирует данные, рассчитывает метрику среднего рейтинга для отфильтрованных активов и осуществляет точечный поиск по заданному пользователем жанру, сортируя выдачу по убыванию качества.
