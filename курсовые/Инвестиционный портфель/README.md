# Анализ риска и доходности акций BMW (1996-2026)

Курсовая работа, посвященная анализу финансовых временных рядов и оценке инвестиционной привлекательности активов на примере акций компании BMW.

## 🛠 Технологический стек
* **Язык программирования:** Python
* **Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn

## 📈 Какую задачу решает проект?
Скрипт проводит автоматический расчет ключевых инвестиционных метрик по годам:
1. Расчет ежедневной и среднегодовой доходности на основе скорректированных цен закрытия (`Adj_Close`).
2. Оценка рисков (годовой волатильности) через стандартное отклонение.
3. Расчет Коэффициента Шарпа для определения эффективности инвестиций в разные периоды.
4. Поиск исторически лучших и худших периодов для инвесторов компании.

## 📊 Результаты и выводы
Проект визуализирует зависимость доходности от рисков в виде интерактивного графика (Эффективная граница), что позволяет наглядно оценить финансовое состояние актива.

## 🚀 Как запустить проект?
1. Скачать файлы `main_2.py` и `BMW.csv` в одну папку.
2. Установить зависимости: `pip install pandas numpy matplotlib seaborn`
3. Запустить скрипт: `python main_2.py`
